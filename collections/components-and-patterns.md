# Components and patterns

Focused galleries for individual website sections and UI patterns.

[Back to the collection](../README.md)

## [ReUI](https://reui.io/)

A shadcn/ui registry of React components, blocks, icons, and templates built with Tailwind CSS. Install components with the shadcn CLI. Components are free, while blocks and icons require paid access.

- **Tags:** components, react, tailwind, shadcn, blocks, icons, templates

## [Ding](https://ding.yusufcengiz.dev/)

A zero-dependency toast notification library with spring animations. New notifications morph the existing toast in place. Available for React, Svelte 5, and plain JavaScript.

- **Tags:** components, notifications, animation, react, svelte, open-source

## [Kibo UI](https://www.kibo-ui.com/)

A free, open-source shadcn/ui component registry with tools such as a color picker, image zoom, QR code generator, and file dropzone.

- **Tags:** components, react, shadcn, open-source

## [Luxe](https://www.luxeui.com/)

A collection of copy-and-paste interface components built with React, Tailwind CSS, Motion, and Radix UI.

- **Tags:** components, react, tailwind, animation

## [Float UI](https://floatui.com/)

A free, open-source collection of responsive Tailwind CSS components and website templates to copy into projects.

- **Tags:** components, tailwind, templates, open-source

## [Ark UI](https://ark-ui.com/)

A headless component library for React, Solid, Vue, and Svelte. Its unstyled controls provide interaction behavior and accessibility support for custom design systems.

- **Tags:** components, react, vue, svelte, design-systems, accessibility

## [CSS Buttons](https://cssbuttons.io/)

A gallery of button designs with links to their code on Uiverse. Browse examples by appearance and copy the ones that fit a project.

- **Tags:** components, buttons, css, inspiration

## [Bencho](https://bencho.dev/)

A collection of interactive React components and micro-interactions, including animated tabs, loaders, card stacks, and drag interactions.

- **Tags:** components, react, animation, interactions

## [Lightswind UI](https://lightswind.com/)

A library of animated React components, UI blocks, and templates, including backgrounds and 3D effects. Some components are free and others require Pro access.

- **Tags:** components, react, animation, backgrounds, blocks, templates

## [Bits UI](https://bits-ui.com/)

A headless component library for Svelte with unstyled controls for building custom interfaces and design systems.

- **Tags:** components, svelte, design-systems, accessibility

## [Avara UI](https://avaraui.com/)

A free collection of interactive React components and blocks built with Tailwind CSS, GSAP, and Motion. Install them with the shadcn CLI.

- **Tags:** components, react, tailwind, shadcn, animation, blocks

## [Transitions.dev](https://transitions.dev/)

A library of UI transitions with a component builder and tools for adding motion through AI agents. The site also offers paid Pro access.

- **Tags:** components, animation, transitions, ai

## [uipkge](https://uipkge.dev/)

An open-source UI registry with components, blocks, charts, maps, and templates for React, Vue, Angular, and Svelte. Install components into a project using the shadcn workflow.

- **Tags:** components, react, vue, svelte, shadcn, blocks, open-source

## [coss ui](https://coss.com/ui)

A component library built on Base UI, with controls such as dialogs, forms, navigation, and data display elements.

- **Tags:** components, react, design-systems, forms, navigation

## [MynaUI](https://mynaui.com/)

A UI collection built with Tailwind CSS, shadcn/ui, and Radix UI, covering interface controls, marketing sections, application screens, and icons, with a Figma design system.

- **Tags:** components, tailwind, shadcn, blocks, icons, figma

## [Magic UI](https://magicui.design/)

A library of free, open-source animated components and effects for React, built with Tailwind CSS and Motion. Paid blocks and templates are also available.

- **Tags:** components, react, tailwind, animation, open-source, templates

## [NeoBrutalism](https://neobrutalism.com/)

A retro-style component library for React and Next.js, formerly called RetroUI. Install its open-source components with the shadcn CLI; paid blocks and templates are also available.

- **Tags:** components, react, tailwind, shadcn, blocks, templates

## [David UI](https://www.creative-tim.com/david-ui)

Creative Tim's library of Tailwind CSS components, including buttons, navigation, forms, and cards. The components are free and open source; the site also offers page blocks and an AI page generator.

- **Tags:** components, tailwind, open-source, blocks, ai

## [Gauge UI](https://www.gauge-ui.dev/)

A library of composable SVG gauge components for React, with a studio for building gauges and examples for dashboards and monitoring. Install the components with the shadcn CLI.

- **Tags:** components, react, shadcn, dashboards, gauges

## [Elements](https://www.tryelements.dev/)

A collection of full-stack shadcn/ui blocks for Next.js and TypeScript, including authentication, AI interfaces, file uploads, and loading indicators.

- **Tags:** components, shadcn, react, blocks, ai

## [Footer Design](https://www.footer.design/)

A gallery dedicated to website footers, with categories for treatments such as large type, grids, cards, and animation.

- **Tags:** components, footers, navigation, typography

## [21st.dev](https://21st.dev/)

A library of React and Tailwind CSS components, templates, and shadcn themes from design engineers. Preview components live, then install them into a project with one command.

- **Tags:** components, react, tailwind, shadcn, templates

## [React Bits](https://reactbits.dev/)

A free library of animated React components, including text animations, backgrounds, and micro-interactions. Copy the source or install it with the CLI, in JavaScript or TypeScript with CSS or Tailwind.

- **Tags:** components, react, animation, backgrounds, tailwind

## [Efferd](https://efferd.com/)

A collection of shadcn/ui blocks for sections such as heroes, auth, dashboards, headers, footers, and calls to action. Install blocks with the shadcn CLI. Some blocks are free, and full access is paid.

- **Tags:** components, shadcn, react, blocks, dashboards

## [Kobra](https://kobra.systems/)

A React and Tailwind CSS component library for navigation, overlays, forms, layout, and feedback, plus AI agent components such as chat history, streaming text, and inline citations. Install components with the shadcn CLI. Some components are free, and a paid plan unlocks more.

- **Tags:** components, react, tailwind, shadcn, ai

## [Torph](https://torph.lochie.me/)

A free, open-source text morphing component that animates between strings, so labels, buttons, and counters change smoothly instead of swapping instantly. It has no dependencies and works with React, Vue, Svelte, or plain TypeScript. Install it from npm.

- **Tags:** components, animation, text, react, vue, svelte

## [Aceternity UI](https://ui.aceternity.com/)

A library of animated React and Next.js components built with Tailwind CSS and Motion, including backgrounds, cards, carousels, text effects, and 3D elements. Copy the code or install it with the shadcn CLI. The components are free, and paid plans add ready-made sections, landing pages, and full website templates.

- **Tags:** components, react, tailwind, animation, shadcn, templates

## [Supahero](https://supahero.io/)

A curated gallery of website hero sections from products and studios such as Linear, Stripe, and Raycast, useful for comparing how sites open their pages.

- **Tags:** components, heroes, sections, landing-pages

## [Uiverse](https://uiverse.io/)

A community-made library of open-source UI elements built with CSS or Tailwind CSS, such as buttons, checkboxes, loaders, cards, and inputs. Everything is free to copy, customize, and use in projects.

- **Tags:** components, css, tailwind, open-source, animation

## [Blookie](https://blookie.io/)

A free collection of shadcn/ui and Tailwind CSS blocks to copy and paste, including heroes, navbars, pricing, testimonials, FAQs, logins, and footers. Blocks are responsive and come in light and dark themes.

- **Tags:** components, shadcn, tailwind, blocks, free

## [Shadcn UI Blocks](https://www.shadcnui-blocks.com/)

A collection of customized shadcn/ui page blocks and components, with sections such as heroes, pricing, logins, FAQs, and footers. Preview each block, then copy its code. The collection is free for personal and commercial projects.

- **Tags:** components, shadcn, blocks, free

## [Shadcn Space](https://shadcnspace.com/)

A large collection of shadcn/ui blocks, components, templates, and dashboard layouts for React and Next.js, with optional Motion animations and support for Radix UI or Base UI. Copy the code or install it with the shadcn CLI, and use the Figma kit to design with the same components. Open-source items are MIT licensed, and a paid plan adds more templates and advanced blocks.

- **Tags:** components, shadcn, react, blocks, templates, figma

## [shadcn/studio](https://shadcnstudio.com/)

A library of shadcn/ui components and blocks for marketing pages, dashboards, and e-commerce, with templates and a theme generator. Copy code or install it with the shadcn CLI. A free tier is available, and full access requires a paid subscription.

- **Tags:** components, shadcn, react, blocks, templates, dashboards

## [Forge UI](https://forgeui.in/)

A library of animated React components, blocks, and full-page templates built for shadcn/ui and Tailwind CSS, using Motion and GSAP. Copy and paste them into a project. Some content is free, and a one-time purchase unlocks premium components and templates.

- **Tags:** components, react, tailwind, shadcn, animation, templates

## [Watermelon UI](https://ui.watermelon.sh/home)

An open-source library of React components, animated interactions, dashboards, page sections, and templates. Each item has a live preview and documentation, and the full templates show how blocks fit together in realistic product pages.

- **Tags:** components, react, open-source, dashboards, templates

## [Wensity UI](https://ui.wensity.com/)

A React and Tailwind CSS library of animated components, UI primitives, and full-page blocks for landing pages and SaaS apps, plus a studio for gradient, shader, and texture backgrounds. Install free items with the shadcn CLI. The free tier includes some components and all primitives under the MIT license, and a paid plan unlocks the rest and the blocks.

- **Tags:** components, react, tailwind, shadcn, animation, backgrounds

## [Libraries.dev](https://libraries.dev/)

A gallery of React UI effect libraries, such as border beams, thinking orbs, gooey, and liquid metal effects, each shared as a prompt to paste into an AI coding agent. The libraries are MIT licensed on npm, and a paid plan adds a studio for deeper customization.

- **Tags:** components, react, animation, ai, open-source

## [Navbar Gallery](https://www.navbar.gallery/)

A gallery dedicated to website navigation bars, with types such as sticky headers, dropdowns, mega menus, sidebars, search bars, announcement bars, and breadcrumbs. Each entry links to the live site, and the blog explains navigation patterns.

- **Tags:** components, navigation, headers, menus

## [Arc UI](https://uiarc.dev/)

A library of animated React components and larger blocks, such as dashboards, charts, maps, and AI chat, built for AI coding agents. Install them with the shadcn CLI or the MCP server, or copy the source. A large set of components and blocks is free without an account, and a one-time purchase unlocks the rest.

- **Tags:** components, react, shadcn, animation, blocks, ai

## [beUI](https://beui.dev/)

An MIT-licensed library of animated components for React and React Native, including motion primitives, blocks, charts, and AI interface pieces. Install web components with the shadcn CLI and preview native ones in Expo Go. A paid Pro plan adds premium blocks and templates.

- **Tags:** components, react, react-native, tailwind, shadcn, animation

## [affectUI](https://www.affectui.com/)

A library of React components, app screens, and blocks for AI products and SaaS, such as agent plans, approval cards, and streamed answers. Each item is a single file with its styles included and no dependencies, installable with the shadcn CLI or through an MCP server. Some items are free and MIT licensed; a one-time purchase unlocks the rest.

- **Tags:** components, react, shadcn, ai, saas

## [Designeer](https://designeer.xyz/)

A curated directory of design galleries, component libraries, design systems, and tools. Browse it to find interface references and resources for building products.

- **Tags:** components, design-systems, inspiration, tools
